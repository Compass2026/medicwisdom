# Medic Wisdom — brand directory

Medic Wisdom (Tim Bobbitt, O'Fallon, Missouri): CPR/AED, First Aid, BLS,
ACLS and EMS education, plus AED rentals. Rebuilt on the Compass Website
Foundation v1 (`Compass2026/showmeelectricalwebsite` @ `f928381`) from the
client's WordPress site at `medicwisdom.wpenginepowered.com`, read Oct 19
2026.

    COMPASS_BRAND=medicwisdom npm run build

- Content comes from the old site. Its copy-paste errors were corrected
  only by reusing each course's own page text. Sources, conflicts and
  everything withheld are in `docs/medicwisdom/decisions.md` (MW-*).
- Colours are the old site's Elementor kit values (`theme.css`).
- Photos with Envato or Pexels file names are stock and are described only
  by what they show. They are never captioned as Medic Wisdom's classes.
- Open items for the owner, including the lapsed `medicwisdom.com` domain:
  `docs/medicwisdom/open-questions.md`.
